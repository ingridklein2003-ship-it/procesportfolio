Opgaven gik ud på at finde et kommercielt website og re-implementere det i HTML, CSS og JavaScript. Hvert teammedlem skulle implementere nok JavaScript til at dække hele pensum — og til sidst optage en fælles forklaringsvideo.

Processen

Fra briefing til merge på fire dage

Dagen begyndte med opgavebeskrivelsen og lidt tid til at stille spørgsmål. Sebastian kom lidt forsinket, men havde medbragt kage som kompensation — skaden var hurtigt glemt.

Den 11. februar kl. 9.00 mødtes vi for at merge vores dev-branches og sammensætte det, der skulle siges i videoen. Vi gik igennem hinandens kode grundigt — for man lærer bedst, når man skal forklare det til andre.

JavaScript-koden forklaret

FAQ-accordion med event bubbling

faq.js
// DOM-selektion: henter alle elementer med klassen .faqItem
const faqItems = document.querySelectorAll(".faqItem");

// For-løkke: itererer igennem NodeList'en ét element ad gangen
for (let i = 0; i < faqItems.length; i++) {
  const item = faqItems[i];
  const question = item.querySelector(".faqQuestion");

  // Event listener: koden kører kun når brugeren klikker
  question.addEventListener("click", function() {
    // classList.toggle: tilføjer "active" eller fjerner den
    item.classList.toggle("active");
  });
}

// Event bubbling: klik bobler op til document
document.addEventListener("click", function(event) {
  const clickedInside = event.target.closest(".faqItem");

  // State reset: lukker alt hvis der klikkes udenfor
  if (!clickedInside) {
    for (let i = 0; i < faqItems.length; i++) {
      faqItems[i].classList.remove("active");
    }
  }
});
01
DOM-selektion
querySelectorAll(".faqItem") returnerer en NodeList med alle elementer der matcher klassen — vores startpunkt for at arbejde med FAQ-boksene.
02
For-løkke
Koden kører ét FAQ-element ad gangen og tilkobler en event listener til hvert spørgsmål. Uden løkken skulle vi gentage koden manuelt for hvert element.
03
Event listener
addEventListener("click", ...) — koden er event-driven. Callback-funktionen kører kun når brugeren aktivt klikker. Intet sker af sig selv.
04
classList.toggle
Tilføjer CSS-klassen "active" hvis den ikke er der — fjerner den hvis den er. CSS bestemmer hvad "active" visuelt betyder: typisk at svaret vises.
05
Event bubbling
Et klik på et element propagerer automatisk opad i DOM-træet. Vi lytter på document for at fange alle klik på siden — uanset hvor de sker.
06
closest() + State reset
closest(".faqItem") søger opad og returnerer null ved klik udenfor. Så fjerner vi "active" fra alle items og lukker accordionen helt.

Refleksion

Hvad tog jeg med mig?

Hvad lærte jeg?

Vigtigheden af god Git-workflow. Dev-branches lod os arbejde parallelt uden at ødelægge hinandens kode — og code review-sessionen den 11. februar var den mest lærerige del. Man forstår bedst sin egen kode, når man skal forklare den til andre.

Hvad var svært?

At koordinere på afstand, da Sebastian arbejdede hjemmefra. Vi skulle kommunikere præcist om hvem der lavede hvad — og få JavaScript-funktioner skrevet separat til at spille ordentligt sammen ved merge.

Hvad var nemt?

Selve opgaveforståelsen var ligetil, og vi fandt hurtigt et godt site. GitHub-setup gik glat da jeg havde erfaring med det fra tidligere. Gruppen supplerede hinanden godt med forskellige styrker.

Næste skridt

Jeg vil skrive mere struktureret og dokumenteret kode undervejs — ikke bare til sidst. Og gerne eksperimentere med moderne features som arrow functions og async/await til næste projekt.
